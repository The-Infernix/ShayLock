Core Architecture

Robust, low-level enforcement mechanisms working in unison.

Mechanic

Accessibility Service Interception

Watches window state changes to track foreground time with precision and intercept key events when blocked.

Mechanic

Permanent Chrome Web Filtering

Inspects Chrome URL bar nodes to detect instagram.com and blocks instantly with zero exceptions.

Mechanic

1-Change/Day Cooldown

Daily limit configuration locked to a single change per calendar day to prevent impulsive adjustments.

Mechanic

3x Capped 5-Min Overrides

PIN unlocks grant exactly 5 minutes and are strictly capped at 3 uses per day until midnight.

Privacy & Safety First

100% local, on-device processing with zero data collection.

ShayLock never transmits browsing activity, app usage, or personal data. All state is stored locally in SharedPreferences. No accounts, no analytics, no backend.

Installation Guide

Get protected in minutes with a simple 3-step setup.

1

Download APK

Download ShayLock-v1.0.0.apk from the GitHub Releases page.

2

Enable Unknown Sources

Allow installation from your browser or file manager when prompted. Android may require this permission depending on your device and Android version.

3

Grant Accessibility & Overlay Rights

Open ShayLock and grant Accessibility Service and Display over other apps (SYSTEM_ALERT_WINDOW) permissions. Notifications are optional but recommended.
